# Scenario engine — v1

## Interpretation
本功能是「依使用者假設，重算同一期間單一通路」的條件試算，不是預測。一次比較最多三個方案；禁止把不同方案的改善金額直接相加。
情境一定從不可變更的 baseline 重新計算，不連續修改上一方案。重新匯入／換期間／換通路後，舊情境標示過期，需重新確認。

## Supported baseline
一個完整且已確認口徑的本期通路。G>0、N>0、0<=D/G<1、0<=R/(G-D)<1，C/P/Q/F/O/A 不可為負；有缺漏、負費用回沖主導或純退款期間則停用情境，仍保留實際金額診斷。
即使通路合計符合條件，按入帳日退款比仍不等於 cohort 退貨機率；介面必須明示，本模型只是固定歷史比率的條件計算。

## User inputs (all explicit)
- v：售出量變化百分比，[-90%, +100%]。必填，預設空白；0 只能由使用者明確確認。
- δ：折扣率變化「百分點」，不是相對百分比；需保證新折扣率在 [0,1)。
- f：單位履約成本變化百分比，[-100%, +100%]。
- a：總廣告支出變化百分比，[-100%, +200%]。
- K：一次性投入，非負 TWD。
輸入範圍是產品防呆設定，不是對真實業務可能性的估計。

## Closed model
沿用 METRICS 符號，先計算 d=D/G、r=R/(G-D)、s=1+v。v/f/a 換成小數、δ 換成百分點/100 後計算：
```
G' = G × s                          # 平均牌價與商品組合固定
D' = G' × (d + δ)
R' = (G' - D') × r                 # 退款金額比固定的模型假設
N' = G' - D' - R'
C' = C × s                         # 每售出量的淨成本及退回結構固定
P' = P × (N'/N)                    # 平台費按原有效淨營收費率估算
Q' = Q × (N'/N)                    # 金流費同上
F' = F × s × (1+f)
O' = O × s                         # 此模型將其他變動費隨量變動
A' = A × (1+a)                     # 不由廣告變動推算銷量
ScenarioContribution = N'-C'-P'-Q'-F'-O'-A'-K
ScenarioDelta = ScenarioContribution - baseline.CM_after
```
費用真實計價可能不等同此模型，例如平台按折扣前 GMV 收費、最低收費、階梯費率或履約固定成本。使用者不能接受以上假設時，顯示「此方案暫不適用」，而不是誤報精確效益。
每個中間值以高精度 Decimal 運算，至最終顯示才 round(2, HALF_UP)。底層總和以未四捨五入數計算；若輸出逐項已取分金額，另顯示 rounding_adjustment 使明細可對帳。

## UX and acceptance
顯示 baseline、五個輸入、所有固定假設、條件結果與注意事項。銷量假設未填，不顯示增益。
調低廣告支出不代表營收固定；必須讓使用者另填 v。可建三個不同 v 的敏感度方案，但不稱為統計信賴區間、不由 AI 指派機率。
第一版不做優化器、商品組合重配、最適預算或因果增量收入。

## Test anchors
- 零變動且 K=0：完全回到 baseline。
- golden 本期 DTC：baseline=270.00。使用者明確填 v=0、δ=0、f=-10%、a=0、K=0，結果=284.00。
- 同情境 K=20，結果=264.00。
- 任一缺必要成本，禁止試算。
