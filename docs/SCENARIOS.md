# Scenario engine — v1

## Interpretation
本功能是「依使用者假設，重算同一期間單一通路」的條件試算，不是預測。一次比較最多三個方案；禁止把不同方案的改善金額直接相加。
情境一定從不可變更的 baseline 重新計算，不連續修改上一方案。重新匯入／換期間／換通路後，舊情境標示過期，需重新確認。

## Supported baseline
一個完整且已確認口徑的本期通路。G>0、N>0、0<=D/G<1、0<=R/(G-D)<1，C/P/Q/F/O/A 不可為負；有缺漏、負費用回沖主導或純退款期間則停用情境，仍保留實際金額診斷。
即使通路合計符合條件，按入帳日退款比仍不等於 cohort 退貨機率；介面必須明示，本模型只是固定歷史比率的條件計算。

## User inputs (all explicit)
- v：售出量變化百分比，[-90%, +100%]。必填，預設空白；0 只能由使用者明確確認。
- δ：折扣率變化「百分點」，不是相對百分比；需保證新折扣率在 [0,1)。
- f：單位履約成本變化百分比，[-100%, +100%]。
- a：總廣告支出變化百分比，[-100%, +200%]。
- K：一次性投入，非負 TWD。
輸入範圍是產品防呆設定，不是對真實業務可能性的估計。

## Closed model
沿用 METRICS 符號，先計算 d=D/G、r=R/(G-D)、s=1+v。v/f/a 換成小數、δ 換成百分點/100 後計算：
```
G' = G × s                          # 平均牌價與商品組合固定
D' = G' × (d + δ)
R' = (G' - D') × r                 # 退款金額比固定的模型假設
N' = G' - D' - R'
C' = C × s                         # 每售出量的淨成本及退回結構固定
P' = P × (N'/N)                    # 平台費按原有效淨營收費率估算
Q' = Q × (N'/N)                    # 金流費同上
F' = F × s × (1+f)
O' = O × s                         # 此模型將其他變動費隨量變動
A' = A × (1+a)                     # 不由廣告變動推算銷量
ScenarioContribution = N'-C'-P'-Q'-F'-O'-A'-K
ScenarioDelta = ScenarioContribution - baseline.CM_after
```
費用真實計價可能不等同此模型，例如平台按折扣前 GMV 收費、最低收費、階梯費率或履約固定成本。使用者不能接受以上假設時，顯示「此方案暫不適用」，而不是誤報精確效益。
每個中間值以高精度 Decimal 運算，至最終顯示才 round(2, HALF_UP)。底層總和以未四捨五入數計算；若輸出逐項已取分金額，另顯示 rounding_adjustment 使明細可對帳。

## UX and acceptance
顯示 baseline、五個輸入、所有固定假設、條件結果與注意事項。銷量假設未填，不顯示增益。
調低廣告支出不代表營收固定；必須讓使用者另填 v。可建三個不同 v 的敏感度方案，但不稱為統計信賴區間、不由 AI 指派機率。
第一版不做優化器、商品組合重配、最適預算或因果增量收入。

## Test anchors
- 零變動且 K=0：完全回到 baseline。
- golden 本期 DTC：baseline=270.00。使用者明確填 v=0、δ=0、f=-10%、a=0、K=0，結果=284.00。
- 同情境 K=20，結果=264.00。
- 任一缺必要成本，禁止試算。

## 管理者改善第二批：條件門檻與敏感度（PL-08）

既有 scenario-v1 五項輸入與閉合公式不變。在原方案已通過 baseline、明填 v 及全部固定假設檢核後，另以 `scenario-sensitivity-v1` 推導銷量門檻；不把門檻當作真實銷量預測或建議配額。

先令 `H=G-D`，在本方案折扣百分點 δ、單位履約變化 f、廣告變化 a 與投入 K 固定時：

```
L = [(G-D-G×δ) × (N-P-Q) - H × (C+F×(1+f)+O)] / H
B = A×(1+a)+K
條件貢獻(v) = L×(1+v)-B
目標 T 的等式銷量變化百分比 = [(T+B)/L-1] × 100
```

δ 是輸入「百分點」除以 100，v/f/a 是輸入相對百分比除以 100。此式只是原閉合公式的代數整理：商品組合、平均牌價、入帳退款金額比、每售出量淨成本、有效平台／金流費率等假設皆仍固定；不適用最低費、階梯費率或其他計價方式的 baseline 不能因衍生分析而繞過限制。

分開兩個目標：`T=0` 為本模型條件行銷後貢獻為零，並非公司淨利損益兩平；`T=原 baseline.CM_after` 為維持原貢獻。L>0 時 v 大於或等於門檻才不低於目標；L<0 時方向相反。L=0 必須分清恆等、恆高於、恆低於目標，不能除以零或宣稱單一門檻。超出 [-90%,+100%] 者明示超界及範圍內是否達標，不在範圍外生成方案。

所有分類用未取分 Decimal 乘积／精確分數比較。介面顯示 12 位小數的近似百分比，另可展開精確分數；不得以近似顯示值決定臨界方向。門檻兩侧的條件結果仍由原 `calculateScenario` 分別重算。

敏感度的 A／B／C 三個銷量變化全部預設空白，由使用者明填後才比較；不預設樂觀、悲觀排序或機率。每個 v 均須在 [-90%,+100%]，沿用同一原 baseline 及方案其他四項輸入，不疊加、不相加改善額。此輪敏感度輸入與結果為本頁暫存分析，不加入方案、決策匯出或工作區備份；介面明示此限制。舊快照標記 stale 時不產生可用的新門檻或敏感度結果。
