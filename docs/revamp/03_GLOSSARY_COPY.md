# 03 名詞對照與文案規格（台灣電商經理人語言）

> 對應批次：R2（全面接線）、R5（規則卡標題）。程式單一來源：`src/i18n/labels.zh-TW.ts`。現行標籤集中在 `src/application/presentation.ts` 的 `metricDefinitions`，R2 改為從 labels 讀取。

## 1. 原則
1. 一個概念一個名稱；正式會計名稱只放在「口徑說明」與技術細節。
2. 名稱要能直接在台灣電商會議上說出口：平台抽成、金流手續費、物流與包材費、廣告投放費、退款。
3. 動詞優先：按鈕用「加入待辦」「看證據」「套用」「計算」；不用「建立行動草稿」「核對」。
4. 數字先於形容：標題寫「折扣多花 118.8 萬」，不寫「折扣負擔上升」。
5. 禁用詞（UI 主層不得出現，技術細節可）：取分、快照、稽核、fact、facts、ID、hash、revision、schema、metric_version、contribution-v1、cohort、blocking、partial、null、JSON（下載選單除外）。

## 7. 規則卡文案（key = `RuleCode`）
格式：**標題模板**（含數字占位）／可能原因／下一步／注意（限制一句）。占位符由應用層格式化：`{dNet}` 淨營收差額、`{dCM}` 扣廣告後貢獻差額、`{cm}` 本期貢獻、`{prevRate}`／`{curRate}` 兩期比率、`{dAmount}` 該費用差額、`{channel}`、`{sku}`、`{missing}`。金額以「萬」為單位四捨五入到一位（例 59.9 萬）顯示於標題，精確值在列內。

| RuleCode | 標題模板 | 可能原因（待確認） | 下一步 | 注意 |
|---|---|---|---|---|
| REV_UP_CM_DOWN | 營收多了 {dNet}，但扣完廣告反而少賺 {dCM} | 折扣加深、退款增加、平台或廣告費上升吃掉了成長 | 看下方拆解找出吃掉貢獻的前兩項，到通路健檢確認是哪個通路 | 差額是結果，不等於原因 |
| NEGATIVE_CHANNEL_CM | {channel} 本期扣完廣告是虧的（{cm}） | 該通路抽成或廣告費高於毛利 | 先確認抽成與廣告費是否正確歸屬，再決定調整投放、價格或商品組合 | 不含固定費與稅 |
| DISCOUNT_BURDEN_UP | 折扣率從 {prevRate} 升到 {curRate}，折扣多花 {dAmount} | 促銷檔期更深、折扣券發放更多、商品組合改變 | 列出本期促銷檔期，核對折扣有沒有換到足夠銷量；評估下一檔折扣深度 | 降折扣要先看銷量反應 |
| REFUND_BURDEN_UP | 退款比從 {prevRate} 升到 {curRate}，退款多 {dAmount} | 上期訂單延後退款、品質或尺寸問題、物流損壞 | 拉退款原因（尺寸／瑕疵／物流），分清是上期訂單還是本期問題 | 這是金額比，不是件數退貨率 |
| FULFILLMENT_BURDEN_UP | 物流費佔比從 {prevRate} 升到 {curRate} | 運費單價上漲、小額訂單變多、包材升級 | 核對物流合約與包材費，確認是單價問題還是訂單結構問題 | 比率上升不等於可省下的金額 |
| MARKETING_BURDEN_UP | 廣告佔比從 {prevRate} 升到 {curRate}，廣告多花 {dAmount} | 投放加碼、轉換變差、營收入帳延後 | 比對各媒體的 ROAS，先縮減表現最差的活動，設定每週檢查點 | 廣告增加不等於浪費，先看帶來的營收 |
| SKU_NEGATIVE_GP | {sku} 本期商品毛利是負的（{cm}） | 成本登錄錯誤、清倉折扣、退款集中 | 先確認成本是否正確；若正確，考慮調價、停售或改搭售 | 只看商品毛利，不含廣告 |
| MISSING_CRITICAL_DATA | {channel} 缺{missing}，相關數字無法計算 | 檔案少列、欄位空白 | 向財務／營運補齊缺漏，補齊前不下結論 | 缺的不是零 |

## 8. 免責集中規則
1. 新增「口徑說明」對話框（`src/components/basis-dialog.tsx`），由頂欄 ⓘ、KPI 抽屜、頁尾連結開啟。內容固定九條：
   - 金額都是**未稅**、依**結帳（入帳）日**計算。
   - 四層數字：淨營收 → 商品毛利 → 通路貢獻 → 扣廣告後貢獻。
   - 不包含：固定費（房租、人事）、所得稅、消費者付的運費收入、平台補貼。所以**扣廣告後貢獻不是公司淨利**。
   - 兩期的差額是「發生了什麼」，不是「為什麼」；也不是可以省下的錢。
   - 合計已包含各通路，各通路的差額不能再加總。
   - 退款比是金額比，不是件數退貨率，也不是同批訂單最終退貨率。
   - 假設試算是「如果這樣做會變多少」，不是預測；三個方案不能相加。
   - MER（淨營收 ÷ 廣告費）常被稱為 ROAS，但沒有媒體歸因；廣告費為 0 時不顯示。
   - 商品頁只看商品毛利；廣告與平台費不分到單一商品。
2. 頁面主層每個區塊最多保留**一句**限制，句型用「注意：…」；其餘搬進技術細節或刪除。
3. 頁尾統一一句：「扣廣告後貢獻不含固定費與稅；兩期差額不等於原因 → 口徑說明」。
4. 單元測試 `tests/copy-density.test.ts`：渲染總覽、健檢、試算三頁，統計主層（排除 `<details>`）含「不是」「不代表」「不等於」「不可」的句子數，各頁 ≤ 3。
