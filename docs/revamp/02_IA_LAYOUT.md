## 2. 全站殼層（`dashboard.tsx`）
```
┌ 側欄 ─┬ 頂欄：麵包屑 ｜ [資料狀態 ●示範資料 · 截至 2026-08-24] ｜ [ⓘ 口徑說明] [AI：未啟用 ▾] [儲存 ▾] [下載 ▾] ┐
│       ├ 期間列（sticky）：通路 ▾ ｜ 比較 ▾ ｜ 前期 ▭—▭ ｜ 本期 ▭—▭ ｜ 快捷：本月 上月 近4週 近12週 去年同期 ｜ [套用] │
│       ├ 範圍一行字：DTC、MARKETPLACE · 等天數（42／42 天）· 前期 … · 本期 …                                   │
│       ├ （partial 時）黃色一行：部分資料待補 → 查看來源問題                                                 │
│       ├ 頁面標題＋一句副標＋主要動作（載入示範 / 匯入）                                                      │
│       ├ ─────────── 頁面內容 ───────────                                                                   │
│       └ 頁尾一句：扣廣告後貢獻不含固定費與稅；差額不等於原因 → 口徑說明                                      │
```
行為規格：
- **AI 狀態**：由 `.ai-availability` 大橫幅改為頂欄小標籤（保留 `data-testid="ai-availability"`、`role="status"`、`aria-live="polite"`）。點開 popover 才顯示完整說明。公開站文字：「AI 解釋未啟用（公開版）」。
- **儲存 ▾**：包含現在 `WorkspaceStorage` 的全部功能（下載完整備份、選取備份、讀取本機副本、同意並保存、刪除本機副本）；未保存變更時標籤顯示「● 未保存」。R6 改為自動保存後，標籤顯示「已保存 14:32」。所有既有 testid 保留。
- **下載 ▾**：目前的「下載目前分析 CSV」「下載資料集設定 JSON」與各頁匯出鈕集中到此選單；各頁內容區不再放下載鈕（匯出區塊保留在會議紀錄頁與假設試算頁的「輸出」區）。
- **期間列**：`position: sticky; top: 0`，高度 ≤ 64px；快捷鈕只填入四個日期並維持「套用」才生效（不改現有 `applyFilters` 語意）。快捷規則見 `05_FEATURES.md §2`。
- **切頁捲動歸零**：`setPanel` 後 `window.scrollTo({top:0})` 並將焦點移到 `main#main-content`（現有 `tabIndex={-1}`）。
- **載入示範資料**：僅在空狀態與資料來源頁顯示；其他頁面的頁首不重複放。

## 3. 經營總覽（`overview.tsx` + `review-workbench.tsx` + `manager-summary.tsx`）
目標順序（由上而下）：
1. **KPI 五卡**（現「核心營運指標」）：淨營收 → 商品毛利 → 通路貢獻 → **扣廣告後貢獻（強調）** → 貢獻率。卡片：本期值、前期值、差額、變動％或百分點；R4 加「目標達成率」小字與「輔助指標」一列（售出件數、廣告佔比、MER、商品毛利率、退款比）。
2. **本期三件事**（來自 `manager-summary.ts` 的優先清單）：每件＝一句白話標題（含金額）＋通路標籤＋「對貢獻影響」金額（紅／綠）＋[看證據] [加入待辦]。門檻輸入收合在「調整門檻」。
3. **兩個關鍵差額**（現「本期經營摘要」的兩張大卡：淨營收差、扣廣告後貢獻差）→ 併入第 1 區的卡片或放在三件事上方一行；不重複出現。
4. **每週趨勢**（保留）＋ R4 檔期標記。
5. **貢獻變化拆解**（橋接）＋**通路比較**（並排，保留）。
6. **期間合計與日均**：改為 `<details>` 收合，預設關閉。
7. **會議設定與決策**（`ReviewWorkbench`）：R1 移到頁尾、收合；R6 搬到「會議紀錄」分頁，總覽只留「本期會議：草稿 → 前往會議紀錄」一行。

通路寬表（前期／本期／差額）移到「通路健檢」頁頂部，總覽不放。

  數據（前期／本期 6 項事實，可點看來源）

## 5. 商品毛利（`Products`）
- 頂部兩張小表：**本期毛利最差 10 個**、**毛利增加最多 10 個**（SKU、品類、本期毛利、差額、毛利率）。
- 下方完整表：欄位順序改為 通路 · SKU · 品類 · 售出件數（本期）· 本期淨營收 · 本期毛利 · **毛利率** · 毛利差額 · 淨營收差額 · 前期淨營收 · 前期毛利 · 資料狀態；其餘欄位進「更多欄位」切換。
- 「資料活動」欄改名「資料狀態」，值改為「兩期皆有」「僅本期」「僅前期」「成本未知」。
- 篩選列：品類、SKU 搜尋、排序、只看負毛利——維持現有行為。
- 說明文字縮為一句：「通路費與廣告不分到商品，這裡只看商品毛利。」

## 6. 假設試算（`multi-scenario-workbench.tsx` + `decision-workbench.tsx`）
- 進頁即顯示：通路選擇（單選，預設第一個通路）→ 本期基準四格 → **方案表單**（方案 1 預設已建立，名稱可改）。不再有「編輯 X 方案」「建立 X 方案工作區」兩層。
- 表單：五個輸入保留；每格右側有「相對 %／絕對值」切換（R5）；上方「套用範本 ▾」。
- 固定假設清單改為收合的 `<details>`「這個試算假設了什麼（必讀）」，勾選「我接受以上假設」在表單內，位置不變。
- 結果：大數字＋與現況相比＋逐項明細表（保留公式列但改中文階梯）；「版本 n」只在按下「計算方案」時遞增，表單輸入中顯示「草稿」。
- 底部：「選入會議」與「輸出」區塊保留。

## 7. 待辦與決議（`actions-workbench.tsx`）
- 頂部切換：**看板**（未開始／進行中／受阻／已完成四欄）｜清單（現行）。
- 行動卡（折疊）：標題（問題）、負責人、期限、狀態、置頂星號、「引用較早資料」徽章。
- 展開編輯：七欄保留；期限用 `type="date"`；負責人用 `<input list>` 帶最近用過的名字；證據選取改為可搜尋的 checkbox 清單（每行：期間 · 指標 · 通路 · 金額）；執行狀態 `<select>` 高度修正。
- 「下載決策工作稿」移到頂欄「下載 ▾」。

## 8. 會議紀錄（R6 新分頁，承接 `ReviewWorkbench`）
```
會議基本：名稱、日期（新增）、固定範圍（來源資料、兩期、通路）、[以目前資料與範圍更新]
議程（自動）：① 關鍵差額 ② 本期三件事 ③ 通路表 ④ 上次決議追蹤（R6） ⑤ 本次選入方案 ⑥ 置頂行動
決議：草稿／採用／補資料再議／不採用 ＋ 備註
上次會議比較：上次的淨營收／扣廣告後貢獻／三件事 vs 本次（同範圍才比，否則顯示原因）
輸出：列印／PDF、Markdown、通路寬表 CSV、Excel（R6）、PPT 一頁式（R6，視決策）
```

## 11. RWD 與可用性
- 1440／1280：側欄固定；期間列單行。
- 768：側欄收成圖示列；期間列兩行；表格橫向捲動容器保留 `tabIndex={0}` 與 `role="region"`。
- 390：側欄變底部分頁列（六個圖示）；KPI 卡兩欄；三件事單欄；表格橫捲；sticky 期間列改為可展開的「範圍：… ▾」一行。
- 字級：說明文字 ≥ 12px（維持）；主要數字 ≥ 20px。
- 鍵盤：Esc 關抽屜回原按鈕（維持）；Tab 可到表格容器（維持）。
