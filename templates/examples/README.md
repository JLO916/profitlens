# 範例範本（含三列示範資料）

這個資料夾放的是三份標準 CSV 與 `manifest.json` 的**填寫示範**，用來對照「每一欄該放什麼、格式長什麼樣」。

- `sales_daily.csv`：每日 × 通路 × SKU 的銷售（未稅商品金額，不含向顧客收的運費）。
- `channel_costs_daily.csv`：每日 × 通路的平台費、金流費、物流履約費、其他變動成本。
- `ad_spend_daily.csv`：每日 × 銷售通路的廣告花費。
- `manifest.json`：資料集設定（涵蓋期間、通路清單、前期／本期）。

## 這不是真實資料

所有通路、SKU、件數與金額都是**虛構示範值**，不代表任何品牌或平台的真實營運結果，也不可拿來當作基準或目標。

## 怎麼換成自己的資料

1. 保留第一列標題，欄位順序與名稱不要改；刪掉三列示範資料，貼上自己的資料。
2. 日期用 `YYYY-MM-DD`；金額用不含 `$`、千分位的數字，最多兩位小數；幣別一律填 `TWD`；不知道的金額留白，不要填 0。
3. 通路名稱可自由命名（例如 `官網`、`蝦皮`），但三份檔案與 `manifest.json` 的 `channels` 必須一致。
4. 費用檔與廣告檔在涵蓋期間內要做到**每一天 × 每一個通路各一列**；當天沒有花費就填 `0.00`。示範只用一個通路，所以三天剛好三列；兩個通路、三天就要六列。
5. 用 UTF-8 存檔（Excel 請選「CSV UTF-8」）。空白範本在上一層 `templates/*.csv`。

欄位定義與完整規則請見 `docs/DATA_CONTRACT.md`。
