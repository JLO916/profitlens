# ProfitLens 繁體中文／台灣電商介面文案

以下是產品文案建議，不是台灣業界唯一標準。改名不得改變資料定義；正式術語與原始欄位保留在說明及來源。

## 一、原則

先講使用者要做的事，再補規則；每個訊息交代「發生什麼／影響什麼／怎麼處理」。同一指標不要交替稱毛利、貢獻、獲利、淨利。不要把退款金額率改成退貨件數率，也不要把 MER 改名成媒體 ROAS。

## 二、導覽與操作

| 目前文字／概念 | 建議主文 | 次要說明 |
|---|---|---|
| 資料工作區 | 資料匯入與檢查 | 匯入銷售、費用與廣告資料，確認資料能否使用。 |
| 通路診斷 | 通路成效分析 | 找出哪個通路的貢獻變好或變差。 |
| 商品毛利 | 商品毛利分析 | 比較商品的銷售與成本，不含未分攤的通路費及廣告费。 |
| 情境試算 | 調整方案試算 | 比較折扣、銷量、出貨成本與廣告費調整後的結果。 |
| 行動摘要 | 改善行動 | 執行追蹤正式做出後再改為「待辦與追蹤」，不只改標籤。 |
| 進階驗證 | 計算驗證（進階） | 使用測試案例檢查計算與資料限制。 |
| 工作區保存與恢復 | 儲存與開啟工作區 | 檔案含本次資料、方案與行動，請保管妥當。 |
| 目前快照 | 本次分析資料 | 進階資訊另顯示資料版本與來源識別碼。 |
| 本期通路基準 | 調整前表現 | 此方案採用的通路、期間與資料版本。 |
| baseline 差額 | 與調整前相比 | 不代表實際已發生的改善。 |
| 本快照證據 | 此行動引用的數據 | 顯示期間、通路、指標和值，不以識別碼為主文。 |
| 排序用已觀察金額差 | 本期較前期差額 | 依實際指標顯示「廣告費增加」「貢獻減少」；不要改為可回收收益。 |
| 精確對帳（橋接一致） | 計算加總一致 | 各項變化合計與貢獻差額相符；不是財務對帳完成。 |
| 來源對照一致 | 與匯入來源加總一致 | 另有獨立控制總額才能標「已與平台／帳務對帳」。 |
| 固定假設 | 本次試算的計算前提 | 主要條件簡述，完整公式收合。 |
| 敏感度 | 不同銷量下的結果 | 使用者自行設定三種銷量假設，不賦予機率。 |
| 停止條件 | 什麼情況下停止／重新評估 | 例如貢獻低於明確門檻；不得讓 AI 擅填承諾數值。 |
| 所需額外資料 | 還需要補哪些資料 | 不應把一般限制或免責文字放在這裡。 |

## 三、指標用語

| 目前文字／概念 | 建議主文 | 不可省略的定義 |
|---|---|---|
| 商品淨營收 | 商品淨營收（未稅） | 折扣前商品收入－折扣－已入帳退款；不含運費收入及未建模項目。 |
| 折扣前商品收入 | 商品銷售額（折扣前） | 還未扣除商家折扣與退款；不要逕稱 GMV，需視來源定義。 |
| 銷貨成本淨額 | 商品成本（已扣成本沖回） | 成本沖回依來源實際入帳；不是退款就自動回沖成本。 |
| 行銷前貢獻 | 廣告前貢獻 | 商品毛利再扣已納入的平台、金流、出貨等變動費用。 |
| 行銷後貢獻 | 廣告後貢獻 | 上項再扣廣告費。目前並非涵蓋所有行銷部門費用。 |
| 行銷後貢獻率 | 廣告後貢獻率 | 廣告後貢獻／商品淨營收；淨營收非正時不顯示比例。 |
| 履約費用 | 出貨相關費用 | 可包含倉儲作業、揀貨、包材、物流，實際項目以匯入來源為準；不可直接縮成只有物流運費。 |
| 單位履約成本變化 | 每件出貨成本調整 | 模型依售出件數變動；若實際按訂單／包裹計費，需確認模型適用性。 |
| 退款金額比 | 退款金額占比 | 本期已入帳退款／扣折扣後、扣退款前商品收入；不是件數退貨率或同批訂單最終退貨率。 |
| 混合行銷效率 MER | 整體營收／廣告費（MER） | 此產品使用商品淨營收／廣告費，不是媒體歸因 ROAS。 |
| 銷售目的通路 | 銷售通路 | 例如官網、蝦皮、momo；Meta、Google Ads 是廣告平台，不是這個欄位的銷售通路。 |
| SKU | 商品編號（SKU） | 新增選填商品名稱，不以名稱取代穩定識別碼。 |
| DTC / MARKETPLACE | 官網／電商平台 | 僅對預設示範代碼建立顯示別名；使用者通路實名依其設定，不能一律硬改。 |

主指標下方固定短註：**「未扣固定費與所得稅，不等於公司淨利。」**

詳細說明：「從商品淨營收扣除商品成本及已納入的通路、金流、出貨等變動費用，再扣廣告費。未納入項目請查看資料口徑。」

## 四、可直接替換的完整文案

### 初次進站

標題：**營收有成長，貢獻有跟上嗎？**

說明：匯入銷售、費用與廣告資料，找出貢獻變化最大的通路與商品，並比較調整方案。

主要按鈕：**用我的資料分析**
次要按鈕：**先看示範**

提示：預設不會上傳原始檔案。要保留下次使用，請儲存工作區。

### 已有資料時

主要按鈕：**更新資料**
次要按鈕：**儲存工作區**
「載入示範」收進其他操作，覆寫前確認。

### 缺商品成本

標題：**部分商品缺少成本資料**
說明：目前可以查看營收，但受影響的毛利與貢獻尚無法計算。請補上標示列的商品成本後重新匯入。
按鈕：**查看需補資料**

### 缺廣告日期

標題：**有些日期尚未提供廣告費**
說明：缺資料不代表沒有投放。若該日確實沒有廣告支出，請確認填入 0；尚未取得帳單則維持待補。

### 引用舊資料，但任務仍可執行（需先修好狀態逻辑）

標題：**此行動引用較早版本的資料**
說明：你仍可更新負責人、期限與進度。需要改用新資料時，請重新確認引用數據；原始紀錄會保留。
按鈕：**檢視原始數據**／**更新引用數據**

### 試算

主文：**依目前假設，調整後廣告後貢獻為 NT$X，較調整前增加 NT$Y。**
說明：這是依你設定的銷量、折扣與費用試算，不是已實現成果。

門檻敘述採動態分支：
- 若容許銷量下降且模型斜率為正：「其他條件不變，銷量最多可下降約 X%，仍可維持調整前貢獻。」
- 若需銷量增加：「其他條件不變，銷量至少需增加約 X%，才可維持調整前貢獻。」
- 零／負斜率、界外與不適用分开呈現，不套上述句型。

顯示值僅供閱讀，門檻判斷仍用精確值，必要時保守捨入；不顯示十二位小數給主管。

### AI 未開啟

**此展示版未啟用 AI。數據計算、規則分析與方案試算仍可使用。**

正式啟用的傳送說明：
「你同意後，系統才會經 ProfitLens 伺服器，將下方摘要資料傳送至 OpenAI。原始 CSV 不會隨請求傳送。請確認摘要不含不應分享的資訊。」

不得聲稱供應商永不保留；不得把雲端轉送寫為使用者本機伺服器。

### 儲存

**本次修改尚未儲存。**關閉分頁可能失去修改。請先儲存工作區檔案，或選擇保留在這個瀏覽器。

已儲存：**已儲存在這個瀏覽器；不是雲端備份。**共用電腦請避免保存敏感營運資料，使用完可清除。

### 沒觸發規則

**這次沒有符合目前提醒條件的項目。**這不代表已達成目標，也不代表所有問題都已排除。

## 五、數字呈現

主要卡片預設整數元或萬元，細節保留小數。百分比一位小數，率差標「個百分點」；倍數標「倍」。不同符號不用只依賴紅綠色，增加「增加／減少／轉正／轉負」文字。前期非正時不顯示誤導成長率。
